# Rota antiga de evento

As páginas dessa rota servem como compatibilidade para links já publicados. O botão de ingresso leva ao checkout interno em `/ingressos/`; nenhuma compra é encaminhada para outra plataforma.

Novos cards da agenda devem apontar diretamente para `/ingressos/?evento=<slug>`. Os eventos, lotes e preços estão em `../ingressos/eventos.json`.
